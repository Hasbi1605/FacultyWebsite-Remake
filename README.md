# FTI UMBY Website Remake

A static remake of the Faculty of Information Technology (FTI), Universitas Mercu Buana Yogyakarta website, built with plain HTML, CSS, and JavaScript.

**Live demo:** https://hasbi1605.github.io/FacultyWebsite-Remake/

## Pages

- `index.html` — Home
- `profil.html` — Faculty profile
- `berita.html` — News
- `informatika.html` — Informatics study program
- `Sisteminformasi.html` — Information Systems study program
- `kontak.html` — Contact
